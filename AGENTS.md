- Fetch the official `jellyfin/Swiftfin` repository through the `upstream` remote and merge `upstream/main` into Alphane. Preserve the upstream commit history with a real merge commit.
- Do not replace an upstream merge with handwritten reimplementations, selective backports, or cherry-picks.
- Review the incoming changes against Alphane's existing behavior and tests, especially Home discovery, playback completion, episode continuation, focus restoration, navigation, branding, and Top Shelf.
- Discard upstream changes that break Alphane's behavior. Record the rejected changes and the concrete regression in the merge commit message.
- Resolve merge conflicts by retaining compatible upstream improvements and Alphane's custom behavior. Keep Alphane project paths, module names, and branding, along with Swiftfin's licensing and attribution.

### Coverage and evidence

- Derive the inventory from root/tab navigation, every `NavigationRoute+*.swift` factory, direct sheets/full-screen covers, alerts, confirmation dialogs, context menus, component-owned presentations and playback supplements. Following only the usual Home navigation path is insufficient.
- Determine tvOS reachability and compile-time conditions before flagging shared code. Record iOS-only, unused/legacy and system-owned surfaces separately; a route declaration by itself does not prove that users can reach it.
- Audit meaningful entry paths and states: initial setup, saved/public/manual profiles, expired credentials, PIN, multiple servers, admin/capability-gated features, loading, empty, failure, disabled controls, missing artwork and short/long text.
- For buttons and selectors, check focused, unfocused, selected-but-unfocused, pressed and disabled states. Verify initial focus, directional navigation, entry into active selection groups, Back behavior and restoration of the previous focus. Validate representative flows on the physical Apple TV as well as the simulator.
- Compare against Alphane's shared controls: inactive text at 80% white; stencil/pill text buttons with distinct focus and active-selection states; artwork with an outside focus border and no resizing or layout shift. Account for deliberate exceptions such as the player progress bar, status icons, native keyboard and OS-owned dialogs. Do not treat every `.capsule` call as legacy styling; it is an Alphane style too.
- Capture the actual rendered views using isolated sample data. Keep current screenshots separate from proposals and label their source revision, entry path, state and focus. Avoid changing real watch history; if real playback is necessary, use only the CAD series.
- Static searches for old styles, plain buttons and new presentation points are supporting checks, not proof that a screen is visually correct. A new or changed tvOS destination/presentation must be added to the inventory or given an explicit exclusion.
- Do not call the audit complete while reachable views or relevant states lack evidence. Report unchecked coverage and unresolved decisions explicitly, including inherited proposals that have not been implemented.
